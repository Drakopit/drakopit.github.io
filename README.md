# Patrick Faustino Camello · Portfolio

The [portfolio](https://drakopit.github.io/) covers my IAM engineering work at Bradesco and the projects I build in public. The [GameForgeJS portal](https://drakopit.github.io/gameforgejs/) contains the engine, Editor, showcase, demo catalog, and playable example routes.

This site uses plain HTML, CSS, and JavaScript. Open `index.html` locally or serve the repository root with a static HTTP server. The GameForgeJS demos are self-contained static builds under `gameforgejs/demos/<demo-id>/play/`; Online Sandbox is not marked playable because it requires a backend.
