A JavaScript game engine

Build the game, one system at a time.

GameForgeJS is a browser-game project built around an entity-component-system design. Its modules cover scenes, input, audio, rendering, and physics, giving experiments room to start small and grow.

A practical path

From the first scene to a playable idea

Use a scene to frame the game, combine entities with the parts they need, then add behavior through systems. The examples show how that foundation can support distinct styles of play.
