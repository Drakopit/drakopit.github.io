The runtime

Build the game, one system at a time.

GameForgeJS is a JavaScript browser-game engine with core, 2D, and 3D entry points. Its class-based components and systems organize reusable behavior around game scenes.

Current runtime modules

A modular foundation

The current package exposes separate core, 2D, and 3D entry points. Type declarations and source are maintained in the public engine repository.

gameforgejs/core

Game lifecycle, scenes, input, audio, assets, and shared utilities.

gameforgejs/2d

2D rendering and physics modules.

gameforgejs/3d

3D rendering and physics modules.

Verified current API

Network module

The current engine package exports a separate gameforgejs/network entry point. Its public exports include client and message primitives, local and WebSocket adapters, state synchronization, and online chat/entity/player helpers.

Connections

NetworkClient

Exports GameNetwork, NetworkClient, and local or WebSocket client adapters.

State

Synchronization

The API exports NetworkMessage, NetworkStateSync, and OnlineEntitySync.

Online helpers

Chat and players

ChatManager and OnlinePlayerManager are part of the current module exports. This does not imply a public hosted backend.
